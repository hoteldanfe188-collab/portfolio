Put your favicon image here and name it exactly:

    favicon.png

(A square image, ideally 512x512px, works best. A simple logo, initial,
or icon reads better than a full photo at small sizes.)

The site already links to "images/favicon/favicon.png" in index.html,
so no code changes are needed once the file is in place.

Alternative: you can also upload a favicon through the admin panel
under Site Settings — if one is set there, it overrides this file
automatically without editing any code.
